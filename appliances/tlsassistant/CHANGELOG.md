# Changelog

All notable changes to the TLSAssistant appliance will be documented in this file.

## [1.0.0] - 2026-10-08

### Added

- Initial release of the ephemeral appliance wrapping the official _stfbk/tlsassistant_ Docker container
- Native integration with S3-compatible object storage providers to store generated PDF assessment reports
- Automated reporting to OpenNebula via OneGate, delivering URLs directly into the Sunstone VM Template tab
- Out-of-the-box configuration profiles for auditing targets against regulatory guidelines
